Custom fields
Add your own fields to Accounts, Prospects, Policies, or Carriers. They'll show up on the edit forms and on the record's Details panel.
One-time setup required: before values you enter here will actually save, run this once in your Supabase project's SQL editor: 
alter table clients add column if not exists custom_fields jsonb default '{}'::jsonb;
alter table prospects add column if not exists custom_fields jsonb default '{}'::jsonb;
alter table policies add column if not exists custom_fields jsonb default '{}'::jsonb;
alter table carriers add column if not exists custom_fields jsonb default '{}'::jsonb;
Until you run it, everything else on the form still saves fine — you'll just get a heads-up toast that the custom field values didn't stick.
Database updates
The commission split, billing, premium audit, endorsement, loss run, umbrella scheduling, COI, and non-admitted carrier features added in this update each store their data in one small new column. Nothing here is required — every existing feature keeps working without it — but run this once in your Supabase project's SQL editor so those specific fields start saving:
-- Policies: billing, renewal commission, surplus lines, premium audit, endorsements, loss runs, umbrella scheduling
alter table policies add column if not exists renewal_commission_rate numeric;
alter table policies add column if not exists bill_type text;
alter table policies add column if not exists surplus_lines_tax numeric;
alter table policies add column if not exists audit_required boolean default false;
alter table policies add column if not exists audit_date date;
alter table policies add column if not exists audit_status text;
alter table policies add column if not exists audit_premium_change numeric;
alter table policies add column if not exists endorsements jsonb default '[]'::jsonb;
alter table policies add column if not exists loss_run_requests jsonb default '[]'::jsonb;
alter table policies add column if not exists umbrella_underlying jsonb default '[]'::jsonb;

-- Carriers: non-admitted / surplus lines flag
alter table carriers add column if not exists non_admitted boolean default false;

-- COIs: additional insured, waiver of subrogation, recurring renewal
alter table cois add column if not exists additional_insured boolean default false;
alter table cois add column if not exists waiver_of_subrogation boolean default false;
alter table cois add column if not exists recurring boolean default false;
Until you run it, everything else on the form still saves fine — you'll just get a heads-up toast naming the specific field that didn't stick.
